# Le Compagnon d'investissement

**Le compagnon d'investissement** est une application mobile développée avec Flutter, conçue pour
accompagner les utilisateurs débutants à intermédiaires dans la découverte et la compréhension de
l'investissement boursier. Adoptant une approche résolument pédagogique par l'interaction et la
simulation sans aucun risque financier, elle permet d'explorer des actions et ETF via des données
réelles (API Alpha Vantage), de gérer un portefeuille fictif, d'expérimenter des scénarios
d'investissement régulier (DCA) et de comparer ses performances à un classement ludique simulé.
Dotée d'une expérience visuelle soignée (graphiques interactifs, animations fluides) et d'une
gestion de cache robuste pour un fonctionnement hors-connexion, l'application rend l'apprentissage
des concepts financiers accessible, intuitif et motivant.
